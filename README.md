## ✨ Overview

Phoenix OS is a **Constitutional AI-powered trading terminal** with a premium Tokyo Night glassmorphism interface. It combines real-time market data, AI-driven trading strategies, and a self-governing Constitutional AI layer (SCE Protocol) that ensures ethical, transparent, and risk-aware trading decisions.

### 🎯 Key Features

- **🏛️ Constitutional AI (SCE Protocol)** - Self-critiquing AI that filters all responses through 10 ethical principles
- **📊 Native TradingView Charts** - Professional-grade charts with zero external dependencies
- **🤖 Autonomous Trading** - AI bot with manual/ai/hybrid trading modes
- **💼 Paper Trading Simulator** - Practice with $1,000,000 virtual funds
- **🔒 Drift Lock Verification** - Mathematical proof of constitutional compliance
- **🎨 Tokyo Night UI** - Premium glassmorphism with neon cyan/purple accents
- **⚡ Real-time Kernel Connection** - WebSocket with zero-auth for local development

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Python 3.10+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/alchemyflownode/rezonic-agentic-OS.git
cd rezonic-agentic-OS

# Install frontend dependencies
cd apps/phoenix-frontend
npm install

# Start the frontend
npm run dev

# In another terminal, start the kernel
cd ../phoenix-kernel
pip install -r requirements.txt
python phoenix_kernel_v14c.py
