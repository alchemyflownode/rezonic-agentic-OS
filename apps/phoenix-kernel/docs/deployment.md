# Phoenix Kernel Deployment Guide

## Prerequisites

### Hardware
- NVIDIA GPU with 12GB+ VRAM (RTX 3060 or better)
- 16GB+ RAM
- 50GB+ free disk space

### Software
- Python 3.10+
- Docker Desktop (for containerized deployment)
- Git
- Ollama (for local LLM)
